# TIS Homepage Redesign

A modern, responsive homepage redesign for **Tulas International School (TIS)**, built as a frontend development assignment.

## Live Website

https://tis-homepage-redesign-sepia.vercel.app/

## GitHub Repository

https://github.com/k00465710-rgb/tis-homepage-redesign

## Technologies Used

- React
- TypeScript
- Vite
- CSS Modules
- CSS
- Intersection Observer API

## Features

- Responsive school homepage layout
- Hero section with call-to-action
- About section
- Academics section
- Campus section
- Sports section
- Contact section
- Scroll-triggered reveal animations
- Light/Dark theme switcher
- Scroll progress indicator
- Responsive navigation
- Component-based React architecture

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/k00465710-rgb/tis-homepage-redesign.git
```

### 2. Open the project

```bash
cd tis-homepage-redesign
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in the terminal.

## Production Build

To create a production build:

```bash
npm run build
```

## Deployment

The project is deployed using Vercel.
